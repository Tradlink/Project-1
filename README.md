# Data Analysis: Bank Marketing and Public Health Coverage

## Overview
This project provides a comprehensive analysis of:
- Bank marketing data, focusing on customer engagement.
- Public health coverage data, emphasizing age distribution and demographic trends.

## Features
- **Data Preprocessing**: Cleaning and transforming data for analysis.
- **Visualization**: Histograms, box plots, and bar charts.
- **Statistical Analysis**: T-tests to compare demographic groups.

## Key Insights
- Identified outliers in customer contact frequency.
- Analyzed education distribution and numeric mapping for regression analysis.
- Explored age distribution by public health coverage status.

## Technologies Used
- Python (pandas, numpy, matplotlib, seaborn, scipy)
- Statistical methods (IQR, t-tests)
- Data visualization (histograms, box plots, bar charts)

## How to Run
1. Install required libraries: `pip install pandas numpy matplotlib seaborn scipy`.
2. Update file paths in the script to match your dataset locations.
3. Run the script in a Python environment.

## Files
- **analysis.py**: Main script for data preprocessing and analysis.
- **bank_marketing_training.csv**: Bank marketing dataset.
- **ASEC.csv**: Public health coverage dataset.

## Results
- Statistical summaries and visualizations for exploratory data analysis.
- Insights into customer demographics and public health trends.
